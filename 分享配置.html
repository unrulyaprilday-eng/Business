编辑分享渠道
Facebook 分享 App ID 配置
  1. 登录 Meta for Developers → My Apps → Create App → 选择 Other → Business，创建应用。
  2. 进入应用 → Settings → Basic，填写 App Domains；如果站点有多个域名，都需要添加到应用域名。隐私政策、服务条款以及用户数据删除网址随意填个网址即可，然后将应用发布。
  3. 复制应用的 App ID，填写到本后台的 Facebook App ID 配置项并保存。

注意：App ID 必须使用已发布（Live）的 Facebook App。

链接地址 不可编辑，由前端按渠道标识和当前页面 URL 自动拼接。
